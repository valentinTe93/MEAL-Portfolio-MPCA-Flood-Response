# MEAL Portfolio: MPCA Flood Response

## Project Overview

A practical MEAL portfolio project simulating a humanitarian multipurpose cash assistance response to flooding in coastal Côte d'Ivoire.

The project follows the MEAL DPro approach and demonstrates how programme logic is translated into measurable results, data-collection tools, datasets, analysis and decision-making.

## Project Objective

To demonstrate practical entry-level MEAL skills through the development of a complete simulated MEAL cycle.

## Important Disclaimer

This is a simulated portfolio project.

All programme scenarios, household data, survey responses and findings are fictional and created for learning and professional skills demonstration.

They should not be interpreted as real humanitarian field data or programme results.
